<AnswerBlock>

Square Share funguje s každým nástrojem pro tvorbu webu, který dovolí vložit do stránky HTML kód: tam patří kód výlohy. Tlačítko pro nákup je obyčejný odkaz, takže funguje v každém nástroji s tlačítky nebo odkazy. Některé nástroje spouští vložené skripty jen v placených tarifech. Tabulka níže ukazuje, kam kód v každém patří.

</AnswerBlock>

## Kam patří kód v jednotlivých nástrojích?

| Nástroj | Kam vložit kód | Potřebný tarif |
| --- | --- | --- |
| [WordPress](/cs/tvorba-webu/wordpress) | Blok Vlastní HTML | Vlastní instalace: žádný, ale uložit ho musí Administrátor nebo Editor. WordPress.com: placený tarif se zapnutými funkcemi hostingu. |
| [Squarespace](/cs/tvorba-webu/squarespace) | Blok Code | Core, Plus nebo Advanced |
| [Wix](/cs/tvorba-webu/wix) | Embed Code, potom Embed HTML | Nápověda Wixu ho neuvádí |
| [Webflow](/cs/tvorba-webu/webflow) | Prvek Code Embed | Placený tarif webu |
| [Framer](/cs/tvorba-webu/framer) | Embed nastavený na HTML | Nápověda Frameru ho neuvádí |
| [Carrd](/cs/tvorba-webu/carrd) | Prvek Embed s typem Code | Pro Standard nebo vyšší |
| [Webnode](/cs/tvorba-webu/webnode) | Obsah HTML | Prémiový balíček, u projektů založených po 26. červnu 2023 |
| [Google Sites](/cs/tvorba-webu/google-sites) | Insert, potom Embed, potom Embed code | Neuvádí se |
| [Shopify](/cs/tvorba-webu/shopify) | Sekce Custom Liquid v editoru motivu | Motiv Online Store 2.0 |

Tlačítko pro nákup v žádném z nich konkrétní tarif nepotřebuje.

## Které nástroje berou jen odkazy?

V těchto nástrojích použijte místo kódu tlačítko pro nákup nebo odkaz na vlastní stránku výlohy:

| Nástroj | Co funguje |
| --- | --- |
| [GoDaddy Website Builder](/cs/tvorba-webu/godaddy) | Odkazy. GoDaddy spouští vložený kód ve vlastním rámu, kde se výloha nezobrazí. |
| [Notion](/cs/tvorba-webu/notion) | Odkazy. Veřejné stránky v Notionu vložený kód nespouští. Nástroje postavené na Notionu jako Super ano. |
| [Hostinger Website Builder](/cs/tvorba-webu/hostinger) | Odkazy. Zda kód výlohy funguje v jeho prvku Embed code, zatím není ověřené. |

## Co platí ve všech nástrojích?

- Vložený kód běží na zveřejněném webu, ne v editoru nástroje. Vždy kontrolujte živou stránku.
- Adresa v řádku prohlížeče musí být v **Povolených doménách** na stránce **Sdílet** výlohy. Bezplatná adresa nástroje (třeba `vasweb.webflow.io`) a vaše vlastní doména jsou různé domény. Viz [Jak fungují povolené domény?](/cs/instalace/povolene-domeny)
- Stránka musí používat https.
- Pokud nástroj skripty odstraňuje, verze **Jen iframe** na stránce Sdílet žádný skript nemá. Má pevnou výšku 640 px.

Tento kód vkládáte. Tlačítko **Kopírovat kód pro vložení** v panelu do něj doplní váš klíč:

<Snippet>

```html title="Kód Skript"
<div data-squareshare-storefront="YOUR-EMBED-KEY"></div>
<script async src="https://embed.squareshare.eu/widget.js"></script>
```

</Snippet>

## Co když můj nástroj v seznamu není?

Na stránce Sdílet zvolte v poli **Váš nástroj pro tvorbu webu** možnost **Jiný web** a vložte kód do toho, co váš nástroj nabízí pro čisté HTML: blok HTML, prvek pro kód nebo vložený obsah. Pokud nic takového nemá, přidejte raději [tlačítko pro nákup](/cs/instalace/pridani-tlacitka-pro-nakup). Odkaz na adresu umí přidat k tlačítku každý nástroj.
